История создания

Язык Ruby создал японский программист Юкихиро Мацумото, которого все называют просто «Мац». Работу над языком он начал 24 февраля 1993 года, а первая публичная версия вышла в декабре 1995 года. Мац хотел получить язык более объектно-ориентированный, чем Perl, и более удобный, чем Python. Он взял идеи из Perl, Smalltalk, Eiffel, Ada и Lisp.

Название языка выбрали в шутку: у Perl («жемчужина») и у Ruby («рубин») названия связаны с драгоценными камнями1. Главный принцип, которым руководствовался автор, он описал так:

Я хочу, чтобы программисты были счастливы — Юкихиро Мацумото

Долгое время Ruby был известен в основном в Японии. Всё изменилось в 2004 году, когда Дэвид Хайнемайер Хансон выпустил веб-фреймворк Ruby on Rails. Благодаря ему язык быстро стал популярен во всём мире. На Ruby написаны, например, GitHub и Shopify. Сейчас язык развивается как проект с открытым исходным кодом2.

Ключевые события в истории языка:

  1. 1993 год — Мац начинает разработку Ruby.
  2. 1995 год — выходит первая публичная версия 0.95.
  3. 1996 год — релиз Ruby 1.0.
  4. 2004 год — появление фреймворка Ruby on Rails.
  5. 2013 год — выход Ruby 2.0.
  6. 2020 год — выход Ruby 3.0, который стал втрое быстрее 2.0.

1 Рубин — камень июля, жемчуг — камень июня. 2 Подробнее — на Википедии.

Краткий обзор языка

Ruby — это динамический интерпретируемый язык общего назначения. В нём всё является объектом, даже числа и nil. Синтаксис похож на английский язык, поэтому код читается легко. Программы на Ruby запускаются командой ruby file.rb.

Основные особенности

  • чистый объектно-ориентированный подход;
  • динамическая типизация;
  • блоки, proc и лямбда-выражения;
  • примеси (mixins) вместо множественного наследования;
  • автоматическая сборка мусора.

Где применяется Ruby

  • веб-разработка (Ruby on Rails, Sinatra);
  • автоматизация и скрипты (Chef, Puppet);
  • тестирование (RSpec, Cucumber);
  • разработка игр (Ruby 2D, Gosu).

Термины

Gem
пакет с библиотекой, который устанавливается командой gem install.
Блок
кусок кода, который передаётся методу, например в each.

Примеры кода

Вывод текста и работа с переменными:

# Привет, мир!
puts "Привет, мир!"

name = "Анна"
age = 18
puts "#{name}, тебе #{age} лет"

Класс и метод:

class Student
  attr_reader :name

  def initialize(name, course)
    @name = name
    @course = course
  end

  def info
    "#{@name}, #{@course} курс"
  end
end

student = Student.new("Богдан", 2)
puts student.info

Массивы и блоки:

numbers = [1, 2, 3, 4, 5]

numbers.each do |n|
  if n.even?
    puts "#{n} — чётное"
  else
    puts "#{n} — нечётное"
  end
end

squares = numbers.map { |n| n * 2 }
p squares
